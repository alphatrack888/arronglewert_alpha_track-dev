# Onboarding illustrations

Export the **square illustration card** (gradient background + phone mockup) from
each onboarding step on the Figma "Login & Onboarding" board, at **@3x PNG**, and
save here with these exact names:

| File         | Figma step                     | Mockup screen     |
|--------------|--------------------------------|-------------------|
| `welcome.png`| Onboarding_Step 1 (Welcome)    | Home / Today      |
| `task.png`   | Onboarding_Step 2 (Start task) | Projects          |
| `notes.png`  | Onboarding_Step 3 (Notes)      | Project Notes     |
| `report.png` | Onboarding_Step 4 (See time)   | Report / Week     |

The card is square (264×264 in Figma). Until the PNGs are added, the onboarding
screens fall back to a styled placeholder card automatically.
